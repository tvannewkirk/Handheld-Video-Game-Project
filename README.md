# Handheld Video Game Project
This project demonstrates the assembly of a handheld retro video game device which can play games such as Tetris.

<h2>Tools Used</h2>

- <b>WEP Soldering iron</b>
- <b>0.8 mm lead-free solder wire</b>
- <b>Tweezers</b>
- <b>Wire Strippers</b>
- <b>Desoldering pump/braid</b>
- <b>Flux</b>
- <b>AA batteries</b>
